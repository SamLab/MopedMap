# Дизайн: импорт СНТ Ярославской области

Дата: 16.10.2026

## Цель

Добавить в базу все именованные СНТ/СТ/ДНТ/ДНП Ярославской области из OSM, чтобы посты
о пролётах БПЛА, называющие конкретное садоводческое товарищество (например
«СНТ "Химик-2"»), ставили маркер в реальной точке, а не в региональном центре.

## Ограничения и решения (согласованы с пользователем)

- **Источник — только OSM** (Overpass API). В OSM по Ярославской области размечено
  ~1509 участков `landuse=allotments`, из них именованных ~282; объекты с «СНТ» в имени ~270.
  Публичного полного реестра СНТ нет. Принимаем неполноту как данность.
- **Гибридное правило для родовых имён**: имена-«однослово без цифры» (`наука`, `мечта`,
  `русь`, `полёт`) матчатся только при наличии слова-маркера (СНТ/СТ/…) рядом. Многословные и
  имена с цифрой/дефисом (`волна-2`, `дружба-1`, `химик-2`, `лесная поляна`) матчатся свободно.
- **Маркеры — обычные локации** (как сёла), никакого отдельного типа/иконки.
- **Привязка к Ярославской области**: СНТ не показывается, если в посте явно назван другой
  регион (область/край/республика). Если регион нейтрален или названа Ярославская — показывается.

## Архитектура

### 1. Скрипт импорта `snt_loader.py`

По образцу `settlement_loader.py`. Запрос к Overpass API:

```
[out:json][timeout:280];
area["ISO3166-2"="RU-YAR"]->.a;
(
  nwr(area.a)["name"~"^(СНТ|СТ|СНОТ|СНП|ДНТ|ДНП|ДСК|СДТ|ТСН|КП|К/П)\b",i];
  nwr(area.a)["landuse"="allotments"]["name"];
);
out tags center;
```

- Пользовательский Agent, ретраи, зеркало (`overpass.kumi.systems`) — как в probe-скрипте.
- Дедуп по `(normalize(name), "ярославская область")`.
- Пропуск имён, уже присутствующих в `settlements.json`/`cities.json`/`REGION_ALIASES`
  (в т.ч. уже добавленного `Химик-2`).
- **Не перезаписывает** `settlements.json` целиком: читает текущий список, добавляет новые
  записи, сохраняет (минимальный диф — только новые строки).
- Сеть — только на этапе импорта; рантайм карты сеть к OSM не делает.

### 2. Очистка имён

Функция `clean_snt_name(raw)`:
- Срезать префиксы-маркеры: `СНТ, СТ, СНОТ, СНП, ДНТ, ДНП, ДСК, СДТ, ТСН, КП,
  К/П, Садоводческое товарищество, Садоводчество, Садовое товарищество,
  Коллективный сад, Садовые участки, Дачный посёлок` (+ сокращения/пунктуация).
- Убрать кавычки `" « » '`, хвостовую пунктуацию, `№`, ведущую нумерацию (`10.`).
- Схлопнуть двойные пробелы, `strip()`.
- **Пропустить битые/обрубленные записи**: незакрытые/непарные кавычки,
  оканчивающиеся на `№?`, обрубленные слова (`надежда вои`), конструкции в скобках
  (`(строительство коттеджей)`), чистая латиница (`green park`), пустое имя после очистки.
- Результат: `{"name": <cleaned>, "lat": ..., "lon": ..., "subject": "Ярославская область",
  "snt": true, ["snt_ctx": true]}`.

### 3. Флаги `snt` и `snt_ctx`

Каждая импортированная запись помечается `snt: true` (происхождение — СНТ; используется для
привязки к Ярославской области, раздел 5).

Дополнительно `snt_ctx: true` ставится, если очищенное имя — **одно слово (нет пробела) и не
содержит цифры** (родовое имя; используется для требования слова-маркера, раздел 4).

Примеры:
- `наука`, `мечта`, `русь`, `полёт`, `волжанин` → `snt=true, snt_ctx=true`
- `волна-2`, `дружба-1`, `химик-2`, `лесное-6`, `лесная поляна` → `snt=true` (без `snt_ctx`)

### 4. Загрузка и матчинг (правки `mopedmap.py`)

- **Загрузчик `settlements.json`** (стр. 47–56): копировать опциональные ключи `snt` и `snt_ctx`
  в `SETTLEMENT_DB[lk]` (наряду с `lat/lon/name/subject`). Ключи необязательные → обратная совместимость.
- **`ALL_PATTERNS`** (стр. 4237): передаёт entry `c` как есть → флаги доезжают до матча.
- **Гейтинг `extract_locations`** (стр. ~5512): перед проверками `_is_common_word_name`/header/body,
  отдельная ветка для записей с `snt_ctx`:
  - `_snt_ctx_ok(text_lower, match_start)` — прямо перед матчем (с допуском пробелов,
    кавычек `"«»'`, пунктуации `. , : ; № ( ) -` суммарной длиной ≤ 8) стоит слово-маркер
    `снт|ст|снот|снп|днт|днп|дск|сдт|тсн|кп` (по границе слова).
  - Есть контекст → принять (перекрывает авто-стоп-лист: «СНТ Берёзка» находится, голая
    «берёзка» — нет). Нет контекста → отбросить.

### 5. Привязка к Ярославской области (правки `process_posts`)

Для маркеров, пришедших из импортированных СНТ (`snt: true` — это **все** импортированные
записи, включая родовые с `snt_ctx`):

- На уровне маркеров `process_posts` (после `filter_locations_by_post_region`, стр. ~7955)
  и на уровне источников directions (стр. ~7879–7881) добавить: если маркер — импортированное СНТ
  (`snt`), и `_mentioned` непусто, и `«ярославская область»` не входит в `_mentioned` → отбросить.
- В markers-ветке `_mentioned` нужно вычислить там же (`get_mentioned_region_subjects(post)`) —
  сейчас он считается только внутри `if dir_pairs:` (стр. ~7875).
- Это закрывает fallback `return filtered if filtered else locations` в
  `filter_locations_by_post_region` и fallback `if _fp:` для направлений, при которых одиночный
  Ярославский СНТ переживал бы фильтр в посте про Курскую область.

Существующее поведение для прочих локаций не меняется.

## Поток данных

```
OSM Overpass ──> snt_loader.py ──> clean_snt_name (+snt_ctx) ──> settlements.json
                                                                      │
runtime: settlements.json ──> SETTLEMENT_DB (+snt_ctx) ──> ALL_PATTERNS
                                                                      │
post ──> extract_locations ──> [snt_ctx? → нужен СНТ-контекст] ──> markers
                                                                      │
                       process_posts ──> [импорт. СНТ? → другой регион в _mentioned → drop]
```

## Тестирование

TDD, новый `test_snt_import.py`:
1. Родовое имя с контекстом («СНТ "Наука", Ярославская область») → маркер Наука/Ярославская.
2. Родовое имя без контекста («наука важна для школьников») → маркера нет.
3. Имя с цифрой свободно: «СНТ "Волна-2"» и голое «Волна-2» → маркер.
4. Многословное: «СНТ "Лесная поляна"» → маркер.
5. Региональная привязка: «Курская область, СНТ "Наука"» → маркера Наука нет
   (даже если это единственная локация — fallback не воскрешает).
6. Юнит-тесты `clean_snt_name`: маркеры срезаются, кавычки/мусор чистятся, битые пропускаются,
   `snt_ctx` выставляется ровно для «одно слово без цифры».
7. Регрессы: `test_khimik2` не сломан; прогон существующих temp-тестов; AST OK;
   дифф-регресс по документированным кейсам.

## Риски и митигации

- Новые паттерны не меняют порядок существующих (стабильная сортировка по длине) → нулевое
  влияние на не-СНТ посты.
- Родовые имена при `snt_ctx` фильтруются контекстом → нет ложных срабатываний в обычном тексте.
- Ошибка в очистке имён → мусорные маркеры; митигируется юнит-тестами очистки и пропуском битых.
- Неполнота OSM → часть СНТ не попадёт; расширяемо через повторный запуск `snt_loader.py`.

## Известные ограничения

- Города/районы без явного названия области (например «Курск, СНТ Наука») не отсекают
  Ярославский СНТ — фильтр работает только по явно названному региону (согласовано).
- Имена, совпадающие с частотным словом (в наборе только `берега`), без СНТ-контекста
  по-прежнему подавляются авто-стоп-листом.
