# Дизайн: контекстное гейтирование топонимов в extract_locations

Дата: 2026-08-01
Статус: одобрено (точность важнее полноты; откат возможен через revert одиночного коммита)

## Проблема

`extract_locations` матчит произвольные подстроки текста постов против огромного
гезеттера (84 726 сел + 1 135 городов + региональные алиасы), умноженного на
падежные формы. Паттерны сортируются по длине, побеждает первый совпавший
substring. Любое обычное русское слово, совпадающее с топонимом, даёт ложное
срабатывание. Это системная проблема, а не череда отдельных багов:

- 67 частотных русских слов присутствуют в БД как топонимы (сутка, ваша, кой,
  мирный, моста, республика, голубое, ...);
- 940 названий длиной ≤4 символа (бор, вяз, ям, дол, гай, ...).

Ручной стоп-лист `COMMON_WORD_MATCHES` и точечные фиксы не догоняют: при таком
размере словаря совпадение случайного слова с топонимом гарантировано.

## Решение: контекстное гейтирование

Структура постов предсказуема: блок локаций (header) + тело с формулировками
направлений. Матч топонима принимается только если он находится в «пространственном
контексте» или в блоке локаций.

### 1. Блок локаций (header)

Определение границы: до первого ` - ` (тире с пробелами) или до статусного слова
(`опасность по бпла`, `фиксаци`, `пролёт`, `пролет`, `внимание`, `отбой`).

Пример: `Тимский район, Курская область - пролёты БПЛА в сторону...`
→ header = `Тимский район, Курская область` (до ` - `).

### 2. Пространственные маркеры

Набор предлогов для матчей в теле (предыдущее слово перед матчем):
`от, из, в сторону, со стороны, в направлени, в, на, к, у, через, до, под,
из-под, возле, около, недалеко от, в районе, из-за`.

### 3. Авто-стоп-лист общих слов

Встроенный набор ~300 частотных русских слов. Сканируем БД: если имя топонима
(или его форма) входит в стоп-набор — матч блокируется без жёсткой привязки
к региону. Авто-генерация из БД заменяет ручной `COMMON_WORD_MATCHES`.

### 4. Правила приёма матча (порядок)

1. `is_region` / районный матч (`Курская область`, `Тимский район`) → **принимаем всегда**.
2. Матч в header → принимаем, кроме слов из стоп-листа.
3. Матч в теле → принимаем только если рядом пространственный маркер **и**
   не общее слово.
4. Направленные чанки в `extract_directions` (после `от`/`в сторону`/`в стороу`)
   → доверенные целиком (маркер уже съеден сплиттером). Это чинит «от Харькова»
   без побочных эффектов.

### Сохранение выигрышей

- Харьков/Харьково (CITY_DB приоритет)
- Петропавловка → Советский район (nearest-rayon)
- Курган→Курск (equal-span guard в rayon-обработке)
- auto-remove по региону из extra_context
- ДНР/ЛНР-фильтр
- non-unique local-first

### Риски

- Принято: единичные посты с топонимом в теле без маркера и без региона могут
  потерять маркер (точность важнее полноты).
- Псевдопрепозиции: «в вашу сторону» (ваша — общее слово, блокируется стоп-листом).
