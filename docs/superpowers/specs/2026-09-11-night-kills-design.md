# Header «За ночь N»: извлечение числа сбитых БПЛА из ночной сводки locatorru

Дата: 2026-09-11
Статус: утверждён пользователем

## Цель

В шапку сгенерированной карты добавить сегмент «За ночь N», где N — число БПЛА,
сбитых за прошедшую ночь, из ночной сводки канала locatorru.

Итоговый вид шапки:

```
Угрозы БПЛА | 9 точек | За ночь 777 | 11.09.2026 13:26 МСК
```

## Контекст

- Шапка генерируется в `generate_html` (mopedmap.py:6504).
- `main()` загружает сырые посты `posts` (окно `HISTORY_FETCH_HOURS = 24`) через
  `fetch_all()`; кортежи каналов: `(clean, display, source, dt)`.
- Ночные сводки «За прошедшую ночь …» уже отфильтровываются из маркеров как сводки
  (`за прошедш\w+ ноч` в `SUMMARY_PATTERNS`) — маркеры из них не создаются, поэтому
  сканировать надо сырые посты `posts`, а не `display_markers`.
- Реальный формат поста (locatorru, ID 84746):

  > За прошедшую ночь силами противовоздушной обороны было уничтожено 777 БПЛА над
  > территориями Брянской, Курской, … морей.

## Решение (подход A: извлечение из уже загруженных постов, без лишних запросов)

1. **Регэксп** — anchored, привязан к «за прошедш… ноч… силами … (пво|противовоздушн…
   обороны) … N (бпла|беспилотн…)», чтобы не ловить случайные числа из текста:

   ```
   за прошедш\w+ ноч\w* .{0,80}? (пво|противовоздушн\w+ обороны) .{0,80}?
   (было\s+)? (уничтожен\w*|сбит\w*|перехвачен\w*)
   ( \s+и\s+(уничтожен\w*|сбит\w*|перехвачен\w*) )?
   \s+ (\d[\d\s]{0,9}) \s* (бпла|беспилотн\w+)
   ```

2. **`extract_night_kills(posts)`** — модульный helper:
   - перебирает кортежи сырых постов, учитывает только `source == "locatorru"`;
   - из совпавших выбирает самый свежий по `dt`;
   - возвращает целое число (пробелы в числе удаляются: `1 155` → `1155`);
   - нет совпадений → `None`.

3. **`main()`**: `night_kills = extract_night_kills(posts)` → передаёт в
   `generate_html(..., night_kills=night_kills)`.

4. **`generate_html(posts_data, ..., night_kills=None)`**: при `night_kills` не `None`
   в шапку между «N точек» и датой вставляется сегмент `| За ночь {night_kills} |`;
   иначе шапка остаётся как сейчас (сегмент отсутствует).

## Краевые случаи

- Ночной пост ещё не вышел / старше 24ч / канал недоступен → сегмент отсутствует.
- Несколько совпавших постов (разные дни) → самый свежий по времени.
- Число с пробелами («1 155») → нормализуется до «1155».
- Репосты/другие каналы игнорируются (только `source == "locatorru"`).

## Тесты (TDD)

1. Точный текст поста 84746 → `777`.
2. Вариант «перехвачено и уничтожено N БПЛА» → N.
3. Вариант «было сбито N беспилотных летательных аппаратов» → N.
4. Число с пробелом («1 155») → `1155`.
5. Не-совпадающий пост → `None`.
6. Два совпадающих поста → побеждает новый по времени.
7. Пост не из locatorru (source = "vrv_radar") → `None`.
8. Сквозной: `generate_html(display_markers, night_kills=777)` → в HTML есть
   `Угрозы БПЛА | ... | За ночь 777 | ...`; при `night_kills=None` сегмента нет.
