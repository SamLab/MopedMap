# Направление на границу области вместо столицы

## Цель

Если в тексте поста направление указано только на регион (область/край/республика) без конкретного города, стрелка на карте должна вести на границу этого региона, а не на его столицу.

## Мотивация

Пост: «Дмитриевка, Гавриловский район, Тамбовская область — пролёт 2 БПЛА в направлении Рязанской области.»

Сейчас стрелка идёт на Рязань (столица). Нужно — на ближайшую к источнику точку на границе Рязанской области. Так карта точнее отражает маршрут БПЛА.

## Правила

- Если destination совпадает с регионом (is_region=True, matched содержит «область»/«области»/«областью»/«край»/«края»/«республик») → координаты цели = ближайшая точка на границе региона от источника
- Если destination — конкретный город (is_region=False или matched != регион) → текущее поведение (координаты города)
- Если GeoJSON недоступен или регион не найден → fallback на текущее поведение (столица)
- Применяется ко ВСЕМ регионам (области, края, республики)

## Архитектура

### Новые функции

```
closest_point_on_polygon(lat, lon, polygon_coords) → (lat, lon)
```
- Принимает точку источника и координаты полигона (список колец, каждое кольцо — список [lon, lat])
- Перебирает все рёбра всех колец, находит проекцию точки на ближайшее ребро
- Обрабатывает Polygon и MultiPolygon
- Использует евклидову аппроксимацию (допустимо для масштаба областей ЦФО/ПФО)

```
find_border_point(region_name, src_lat, src_lon, geojson_lookup) → (lat, lon) | None
```
- Ищет регион в geojson_lookup через find_geojson_feature
- Извлекает координаты полигона
- Вызывает closest_point_on_polygon
- Возвращает точку на границе или None

### Пример работы

Пост: «Дмитриевка, Гавриловский район, Тамбовская область — пролёт 2 БПЛА в направлении Рязанской области.»

1. extract_directions находит пары:
   - Дмитриевка(52.0, 41.5) → Рязань(54.6, 39.7) [is_region=True, matched="рязанской области"]
2. process_posts определяет: region-only destination
3. find_border_point("рязанская область", 52.0, 41.5, geojson_lookup)
   — ближайшая точка на полигоне Рязанской области от (52.0, 41.5)
   — результат: ~(53.5, 40.5)
4. Маркер: source=Дмитриевка, dest_name="Рязанская область", direction=[53.5, 40.5]

### Обработка ошибок

- GeoJSON не загрузился (Network error) → статический fallback уже есть (STATIC_GEOJSON_FEATURES), если и его нет → capital fallback
- Регион не найден в geojson_lookup (например, новый регион без полигона) → capital fallback
- Источник внутри региона назначения (rare) → всё равно считаем границу (стрелка будет короткой, что логично)
