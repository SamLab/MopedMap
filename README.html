LocatorRU

Карта угроз БПЛА на основе Telegram-каналов @locatorru и @vrv_radar

Как работает

  1. Загружает посты из каналов @locatorru и @vrv_radar за последние 8 часов
  2. Извлекает названия городов и регионов из текста
  3. Находит координаты по базе (1134 города РФ + регионы)
  4. Открывает карту в браузере с цветными маркерами

Запуск

run.bat

или

python locator_map.py

Можно передать текст напрямую:

python locator_map.py "Курская область - опасность. Брянская область - фиксации."
